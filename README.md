# 專案計畫表

用瀏覽器打開 `index.html` 就能使用的專案排程工具。

- 目前版本：**V1.1**（2026-10-31）
- 線上版本：https://a91031033.github.io/terrytw/
- 各版本變更請見 [修訂紀錄](CHANGELOG.md)

## 功能

- 多專案：最上方的「專案」選單可以切換、新增、複製、刪除專案，每個專案分開儲存；「全部專案備份」可以一次備份所有專案
- 每個階段可設定：階段名稱、開始日期、工期（天）、完成日期、負責人、狀態
- 階段名稱有下拉選單（EVT2／DVT 常用階段），點一下就會列出全部，輸入文字可以篩選，也可以自己輸入新名稱
- 每個階段可以勾選「里程碑」（◆）；工期 1 天或名稱含「Close」的階段預設會勾選。里程碑以完成日期為準，會列在上方的「里程碑」區塊，顯示日期、星期和倒數天數；按「複製文字」可以貼到 Email 或 Teams
- 階段依名稱的第一個字（例如 EVT2、DVT）自動分組，表格和甘特圖的列都會用群組顏色上底色；像「C2 Close」這種只出現一次的名稱，會歸到前一個階段的群組
- 輸入工期會自動算出完成日期；輸入完成日期會自動算出工期
- 勾選「接續」的階段會自動排在上一階段完成的隔天
- 可選擇工期只算工作天（跳過週六、日與國定假日）
- 內建行政院人事行政總處 2026、2027 年辦公日曆表的國定假日（含補假），甘特圖上會標出假日，排程碰到假日會提醒
- 甘特圖以每天一格顯示日期與星期，週末標灰色、國定假日標橘色，並標出今天的位置和已逾期的階段
- 甘特圖可以依群組收合：點群組標題或按「全部收合」後，只顯示里程碑
- 匯出 HTML：產生一個唯讀的網頁檔（依目前畫面，含甘特圖），可以直接用瀏覽器打開或寄給別人，不需要網路
- 匯出 CSV（可用 Excel 打開）、備份／匯入 JSON、列印；匯出的檔名會加上專案名稱和匯出時間，例如 `我的專案_20261030-1514.json`
- 團隊請假：可設定 5 位成員的名字和請假日期（只算工作天），甘特圖下方會用紫色斜線標出每個人的請假期間；階段負責人在負責期間請假時會提醒
- 請假資料可單獨匯出／匯入（`團隊請假_日期-時間.json`），換專案或換電腦都能沿用
- 「階段列表」和「團隊請假」各有鎖定開關（🔓 編輯中／🔒 已鎖定），鎖定後欄位不能修改，避免不小心改到

## 資料儲存

資料會自動存在瀏覽器裡（localStorage），只存在目前這台電腦和這個瀏覽器。
要換電腦或備份時，請用「全部專案備份」（或單一專案的「備份 JSON」）下載檔案，再到另一台電腦用「匯入 JSON」載入；匯入會加入專案清單，不會覆蓋其他專案。
團隊請假和專案分開儲存，匯入另一個專案時不會被覆蓋；要帶到別台電腦，請用「匯出請假 JSON」。
