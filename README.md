# 專案計畫表

用瀏覽器打開 `index.html` 就能使用的專案排程工具。

## 功能

- 每個階段可設定：階段名稱、開始日期、工期（天）、完成日期、負責人、狀態
- 階段名稱有下拉選單（EVT2／DVT 常用階段），也可以自己輸入
- 工期 1 天的階段會自動標成里程碑（◆）
- 輸入工期會自動算出完成日期；輸入完成日期會自動算出工期
- 勾選「接續」的階段會自動排在上一階段完成的隔天
- 可選擇工期只算工作天（跳過週六、日與國定假日）
- 內建行政院人事行政總處 2026、2027 年辦公日曆表的國定假日（含補假），甘特圖上會標出假日，排程碰到假日會提醒
- 甘特圖以每天一格顯示日期與星期，週末標灰色、國定假日標橘色，並標出今天的位置和已逾期的階段
- 匯出 CSV（可用 Excel 打開）、備份／匯入 JSON、列印；匯出的檔名會加上專案名稱和匯出時間，例如 `我的專案_20261030-1514.json`

## 資料儲存

資料會自動存在瀏覽器裡（localStorage），只存在目前這台電腦和這個瀏覽器。
要換電腦或備份時，請用「備份 JSON」下載檔案，再到另一台電腦用「匯入 JSON」載入。
